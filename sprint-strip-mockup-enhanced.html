Design Notes

Structure:
• Dots sit ON the coral progress bar (not below)
• Each dot = task marker (1-2 word label)
• Hover label: brief task name
• Hover tooltip: full description + sprint day
Colors:
• Green — Done ✓
• Coral — In Progress
• Red — Blocked
Interaction:
• Hover → scale up, show label + tooltip
• Drag (future) → reorder if deferred
• Visual feedback: shadow lift on hover
Responsive:
• Desktop (1920px): Full layout, dots visible
• Tablet (768px): Stack vertically, adjust sizing
• Mobile (375px): Simplified, dots smaller, tooltips adjusted
